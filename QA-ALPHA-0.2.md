# PRIME TIME: SHOWDOWN — проверка Alpha 0.2

14 октября 2026. Доработана существующая Alpha 0.1 в той же рабочей папке. Стек, меню, снаряжение, 3D-арена, шесть карт, три оружия, карьера, сохранения и GitHub Pages сохранены. Публикацию через VS Code выполняет пользователь.

## Что изменено

- **Бой:** активное движение с выбором дистанции, боковыми смещениями, уходом от стен, короткими автоматическими уклонениями. Игрок не наследует случайную тактику противника.
- **ИИ:** Aggressive, Tactical, Evasive; у каждого четыре карты и такой же цикл, цены и регенерация, как у игрока. Минимальная задержка реакции на подготовку сильной атаки — 320 мс. Бот не читает будущие действия.
- **Комбинации:** DASH → POWER (+50% урона), SHOCK → POWER (+50%, пока цель оглушена на попадании), SHIELD → OVERDRIVE (+25% урона на 3 с, щит продлевается до 4 с). HUD для SHOCK учитывает время подготовки выстрела и не обещает комбо, когда оглушение закончится раньше попадания.
- **Ощущение боя:** усиленная отдача и реакция тела, отбрасывание, след рывка, электрический разряд, вспышки и расширяющиеся кольца. Тяжёлое попадание: 65 мс hit-stop, попадание по щиту: 25 мс, комбо: 85 мс. Карточки остаются доступны во время короткой остановки симуляции.
- **3D:** более светлый пол и освещение, бегущее табло, пульсирующие панели, дополнительные детали экипировки, живая походка и повороты, подготовка выстрела на оружии, щит и аура форсажа. Камера на результате выделяет победителя.
- **Интерфейс:** открытое окно комбо, выделение подходящей карты, заметные цены и HP, индикатор подготовки вражеского POWER SHOT. При смене карты обновляется только её слот. Четыре выбранные карты видны отдельно в снаряжении; прокрутка при выборе не сбрасывается.
- **Результаты:** VICTORY/DEFEAT, анимация наград, ключевые карты, блокированный урон, прерванные атаки, лучшее успешное комбо и изменение популярности. Кнопки повтора и меню находятся вне прокручиваемых деталей.
- **Звук:** разные выстрелы, звуки всех шести карт, старт, комбо, SHOWTIME, победа и поражение. Синтез Web Audio без внешних ресурсов.
- **Совместимость:** `prime-time.alpha.1` и версия формата 1 сохранены. Старые фанаты, валюта, статистика, оружие, карты и настройки восстанавливаются. Исправление WebGL-диагностики и попытка запуска без сглаживания сохранены.

## Автоматические проверки — успешно

- `npm install --offline --no-audit --no-fund` — зависимости актуальны, новые зависимости не добавлены.
- `npm test` — **53 теста в пяти файлах**, все проходят.
- `npm run build` — строгий TypeScript и production-сборка успешны, предупреждений о размере чанков нет.
- Сборка выполнена с `GITHUB_REPOSITORY=AertoNik/PRIME-TIME-SHOWDOWN`.
- HTML ~1,8 КБ, CSS ~33,5 КБ (8,4 КБ gzip), игровой JavaScript ~62,8 КБ (23,8 КБ gzip), Three.js ~485,9 КБ (122,2 КБ gzip). В сумме около 155 КБ gzip.
- 72 фиксированные дуэли: 12 seed × три оружия × пассивный/активный игрок. **0/36 побед без карт, 29/36 с простым контроллером**, SHOWTIME в 44/72 матчах. Это контрольная серия симуляции, не статистика реальных игроков. Для сравнения, Alpha 0.1 в этой серии давала 19/36 активных побед.
- Проверены все способности, три комбо, истечение окон, щит, дым, оглушение, срыв атак, законность карт и энергии всех трёх ботов, границы и направление движения, нокаут, победа/поражение/ничья, лимит времени, сохранения Alpha 0.1 и повреждённые данные.
- Проверены HTML результата победы и LEVEL UP. Лучший момент сохраняет более сильное успешное комбо, а не просто последнее.
- Восемь серий по 50 выстрелов: размер пулов эффектов постоянен, reset очищает частицы, трассеры, кольца, дым, световые вспышки, тряску и импульс камеры.
- `git diff --check` — без ошибок.

## Проверено в браузере

Использован встроенный браузер Codex с WebGL, desktop и viewport **390×844**, **320×568**.

- Главное меню Alpha 0.2, светлая сцена, боец и анимации отображаются без ошибок JavaScript/WebGL.
- Выбраны все три оружия; предпросмотр и параметры обновляются.
- Выбраны и сохранены разные комплекты из четырёх карт. При снятии нижней карты на маленьком экране сохранена прокрутка (`scrollTop = 403`, комплект 3/4), после возврата карты — снова 4/4.
- Все шесть способностей применены вручную в разных матчах. SHIELD → OVERDRIVE отображается как PERFECT PLAY, блокирует урон и записывается в результат. SHOCK → POWER записано в лучший момент (два комбо за матч).
- DASH спас от сильной атаки: получена надпись DODGE. В одном из запусков усиленный выстрел после DASH был уклонён ботом, что проверяет действующую контригру; комбинация не считается успешной при промахе.
- Проверены регенерация энергии, получение урона, предупреждение POWER SHOT, оглушение, подготовка выстрела, дым, щит, SHOWTIME, пауза, продолжение и повторные бои без вступления.
- Получены экраны поражения с наградами, ключевыми картами, блокированным уроном и комбинациями. Кнопки PLAY AGAIN и MAIN MENU доступны на 320×568; детали результата прокручиваются отдельно.
- Ник AIRWAVE, mute, низкое качество, оружие, карты и прогресс сохраняются после перезагрузки. После проверки звук и автоматическое качество возвращены.
- Карьера показывает накопленные фанаты, валюту в профиле, число матчей, урон и комбо.
- На 320×568: ширина документа и игрового контейнера — 320, высота контейнера — 568; горизонтального скролла нет.

## Production и GitHub Pages

Production-preview проверен на порту 4194 в подпапке `/PRIME-TIME-SHOWDOWN/`: главное меню Alpha 0.2 и 3D-сцена загрузились; вступление, отсчёт, бой, SHOCK и окно комбо, результат с наградами, PLAY AGAIN, пауза и продолжение работают. Повтор выбрал нового противника Tactical вместо Aggressive.

HTML, оба JavaScript-чанка, CSS и favicon возвращают HTTP 200 с корректными MIME-типами; HTML ссылается на готовые assets, а не TypeScript-исходники. Новых предупреждений или ошибок production в консоли не обнаружено. В истории вкладки осталась ошибка HMR от прежнего остановленного dev-сервера 5192; к проверяемой сборке 4194 она не относится. Сам опубликованный сайт Alpha 0.2 не проверялся: изменения ещё не отправлены.

`vite.config.ts` и `.github/workflows/deploy.yml` сохранены. Workflow: `npm ci → npm test → npm run build → upload dist → deploy Pages`. Новых сервисов, токенов или серверных зависимостей нет. Изменения не отправлялись на GitHub.

- Физические iPhone/Android и FPS на слабой GPU не измерены; viewport-тест не заменяет запуск на телефоне.
