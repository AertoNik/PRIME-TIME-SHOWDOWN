# PRIME TIME: SHOWDOWN — Alpha 0.2

Небольшая мобильная 3D-аркада: новичок попадает в боевое телешоу, выбирает оружие и четыре способности, сражается с ботом и набирает фанатов. Все модели, материалы, интерфейсные иконки и звуки создаются внутри проекта. Нет внешних шрифтов, моделей, платных ресурсов или игровых сервисов.

## Запуск

Нужен **Node.js 22.12+ с npm** (рекомендуется актуальный Node.js 22 LTS).

```bash
npm install
npm run dev
```

Открой адрес из терминала. Для телефона подключи компьютер и телефон к одной сети Wi-Fi, затем открой `http://IP-КОМПЬЮТЕРА:5173/`. Сервер слушает все сетевые интерфейсы. При необходимости разреши доступ в локальной сети в настройках брандмауэра. Публикация на Pages даёт обычную HTTPS-ссылку без локального сервера.

```bash
npm run typecheck
npm test
npm run build
npm run preview
```

`build` проверяет TypeScript и создаёт **dist/**. `preview` запускает готовую production-сборку, обычно на порту 4173. Не открывай `index.html` двойным кликом: игре нужен HTTP-сервер.

## Как играть

1. Выбери оружие в **Снаряжении**: SIDEKICK .45 (баланс), CLOSE CALL (дробовик, сближение), NEON REPEATER (скорость и дистанция).
2. Сними одну выбранную карту, чтобы заменить её. В комплекте ровно четыре карты, в руке три. Карта справа от индикатора энергии показывает следующую. После использования сыгранная карта отправляется в конец очереди: случайность только при начальной перестановке.
3. Боец сам перемещается, выбирает дистанцию и стреляет. Ты решаешь, когда тратить восстанавливающуюся энергию. Кнопки **1 / 2 / 3** также активируют карты на компьютере.
4. Жёлтая надпись предупреждает о сильной атаке бота. DASH даёт уклонение, SHIELD снижает урон, SHOCK прерывает подготовку атаки.
5. DASH → POWER SHOT в течение двух секунд усиливает выстрел на 50%. SHOCK → POWER SHOT тоже даёт +50%, если попадание происходит до окончания оглушения: HUD показывает доступное окно. SHIELD → OVERDRIVE в течение двух секунд даёт +25% урона на 3 секунды и продлевает щит до 4 секунд. Дым снижает точность соперника, форсаж ускоряет атаки.
6. На 18-й секунде включается SHOWTIME: оба бойца восстанавливают энергию в 1,25 раза быстрее. Матч длится максимум 75 секунд. При истечении времени выигрывает боец с большим оставшимся здоровьем; равенство даёт ничью.
7. После матча начисляются фанаты и кредиты, даже при поражении. Комбинации и уклонения дают дополнительные фанаты. **PLAY AGAIN** сразу запускает новый матч.

Пауза — кнопка в углу или Escape. При сворачивании вкладки матч ставится на паузу; вернувшись, нажми «Продолжить». Выход с паузы засчитывает поражение и открывает результаты. Вступление показывается только перед первым матчем.

## Прогресс и настройки

Прогресс, ник, оружие, комплект карт, звук и графика сохраняются в `localStorage` этого браузера (`prime-time.alpha.1`). В приватном режиме или при блокировке хранилища игра продолжит работать, но сообщит об отсутствии сохранения. Очистка данных сайта удаляет прогресс. Текущий матч не восстанавливается после перезагрузки. Разные localhost-порты имеют отдельное хранилище браузера; на прежнем опубликованном адресе сохранение Alpha 0.1 продолжит работать.

Карьерные ступени: ROOKIE (0), RISING STAR (400), PRIME CONTENDER (1200 фанатов). Сохранения Alpha 0.1 совместимы: ключ и формат сохранения сохранены, фанаты, оружие, комплект и настройки не сбрасываются. Кредиты — счётчик наград Alpha; магазина и влияющих на баланс покупок нет. Все оружия и карты доступны сразу. Графика автоматически снижает разрешение и число частиц при устойчиво низкой частоте кадров; можно сразу выбрать низкое качество.

## Публикация на GitHub Pages

Workflow `.github/workflows/deploy.yml` автоматически выполняет **npm ci → npm test → npm run build → загрузка dist → публикация Pages** при push в `main` или `master`. Сырой TypeScript не публикуется.

### Новый репозиторий

1. Создай пустой репозиторий на GitHub (например `PRIME-TIME-SHOWDOWN`). Не добавляй автоматически README, если он уже есть локально.
2. В терминале в папке проекта выполни:

```bash
git init
git add .
git commit -m "Release PRIME TIME SHOWDOWN Alpha 0.2"
git branch -M main
git remote add origin https://github.com/USERNAME/REPOSITORY.git
git push -u origin main
```

Заменяй USERNAME и REPOSITORY своими значениями. Если remote `origin` уже существует, проверь `git remote -v`; для смены адреса используй `git remote set-url origin https://github.com/USERNAME/REPOSITORY.git`. Текущая рабочая папка уже связана с `AertoNik/PRIME-TIME-SHOWDOWN`; повторный `git init` и добавление remote ей не нужны.

3. Открой репозиторий → **Settings → Pages → Build and deployment → Source → GitHub Actions**.
4. В **Actions** открой workflow **Deploy PRIME TIME to GitHub Pages**. При необходимости нажми **Run workflow** на основной ветке.
5. После успешного задания `deploy` ссылка находится в **Settings → Pages**, в окружении **github-pages** и в итогах deployment. Для обычного репозитория это `https://USERNAME.github.io/REPOSITORY/`.

Vite получает имя репозитория из `GITHUB_REPOSITORY` в Actions. Для репозитория `USERNAME.github.io` используется корень. Локальная сборка использует относительный base `./`; для отдельной проверки подпапки:

```bash
BASE_PATH=/PRIME-TIME-SHOWDOWN/ npm run build
npm run preview
```

Затем открой `http://localhost:4173/PRIME-TIME-SHOWDOWN/`. Не задавай постоянный абсолютный адрес сайта в коде. Для собственного домена при необходимости укажи `BASE_PATH=/` в окружении шага сборки.

### Обновления

```bash
git add .
git commit -m "Improve the next episode"
git push
```

GitHub Actions снова проверит игру и опубликует новый `dist`. При красном workflow открой первый упавший шаг; при ошибке Pages проверь выбор GitHub Actions в Settings. Токены не нужны в исходниках: GitHub использует ограниченный служебный токен и OIDC внутри Actions.

## Устройство проекта

- `src/main.ts` — жизненный цикл, переходы экранов, фиксированный шаг симуляции, пауза.
- `src/ui.ts`, `src/style.css`, `src/icons.ts` — интерфейс, адаптация, SVG-иконки.
- `src/arena.ts` — Three.js-сцена, камера, студия, качество и WebGL-контекст.
- `src/characters.ts` — составные персонажи, оружие, процедурные анимации.
- `src/effects.ts` — пулы вспышек, трассеров, частиц, дым и тряска.
- `src/combat.ts` — независимая от WebGL боевая симуляция и события для отображения.
- `src/cards.ts`, `src/ai.ts`, `src/movement.ts`, `src/data.ts` — очередь карт, три тактики бота, перемещение и баланс.
- `src/audio.ts` — Web Audio; запуск только после жеста пользователя.
- `src/storage.ts` — проверяемое сохранение и начисление наград.
- `tests/` — боевая логика, три комбинации, законность действий ботов, сохранения, WebGL-диагностика и пулы эффектов; отдельный тест прогоняет 72 дуэли с фиксированными seed.

Для новых режимов можно переиспользовать симуляцию и её события; параметры оружия и карт лежат в конфигурации. Реальный PvP потребует серверной синхронизации и проверки действий, которых в Alpha нет.

## Проверки и границы Alpha

Есть одна процедурная арена, два силуэта бойцов, три тактики бота, три оружия, шесть карт, локальная карьера и полный цикл повторных матчей. Нет регистрации, мультиплеера, сервера, магазина и платных сервисов. Снаряды визуализируют мгновенно рассчитываемые попадания; реалистичная баллистика не используется.

Текущие проверки Alpha 0.2 приведены в `QA-ALPHA-0.2.md`; `QA.md` хранит историю Alpha 0.1. Физический телефон и опубликованный GitHub Pages считаются проверенными только после фактического запуска на них. Подготовленный workflow сам по себе не подтверждает публикацию. Для ошибок загрузки HTML содержит резервное сообщение; потеря WebGL ставит бой на паузу до восстановления контекста.

## Если появляется ошибка 3D в Chrome

Игра использует WebGL2. Если опубликованная ссылка работает в одном браузере, но не запускает 3D в другом, сначала проверь настройки графики проблемного браузера. В Chrome открой `chrome://settings/system`, включи аппаратное ускорение графики, если оно доступно, и перезапусти браузер. [Официальная инструкция Google](https://support.google.com/meet/answer/10058482?hl=ru).

Игра автоматически повторяет создание контекста без сглаживания, если предпочтительная конфигурация не сработала. При ошибке открой «Подробности ошибки»: другие сбои запуска теперь отделены от недоступности WebGL2. Для диагностики Chrome можно посмотреть строку WebGL2 на `chrome://gpu`.

## Что изменилось в Alpha 0.2

- Бойцы активнее обходят друг друга, меняют направление и уходят от стен; дистанция зависит от оружия и тактики. Автоматический короткий сайдстеп не открывает ручное DASH-комбо.
- Aggressive давит, Tactical сохраняет энергию и контратакует, Evasive чаще маневрирует. Каждый бот имеет четыре карты, ту же очередь, стоимость и восстановление энергии, что игрок; реакция на сильную атаку начинается не мгновенно.
- Усилены вспышки, трассеры, отдача, реакция тела, ударные кольца и отбрасывание. Сильное попадание сопровождается коротким hit-stop (65 мс), комбо — 85 мс. Интерфейс остаётся активным.
- Более светлая арена, бегущее табло, пульсирующие панели, реакции зрителей, читаемые щит, оглушение и форсаж. Эффекты используют ограниченные пулы; тяжёлого постпроцессинга нет.
- HUD показывает прогресс подготовки вражеского POWER SHOT, окно комбо и цену карты; заменяется только сыгранная карта. Выбранные четыре карты показаны отдельным рядом в снаряжении.
- В результатах есть VICTORY/DEFEAT, анимированные награды, ключевые карты, блокированный урон, срывы атак и переход популярности. Кнопки повтора и меню доступны на маленьких экранах, детали результата прокручиваются отдельно.
- Звуки оружия и каждой способности различаются; добавлены отдельные сигналы старта, комбо, SHOWTIME и поражения. Mute сохраняется.

Публикация остаётся прежней: пользователь отправляет изменения через VS Code, GitHub Actions проверяет проект, собирает и публикует только `dist`.
