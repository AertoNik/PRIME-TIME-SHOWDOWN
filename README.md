# PRIME TIME: SHOWDOWN — Alpha 1.6.5 «First Broadcast»

Стилизованная мобильная браузерная 3D-игра: тактическая дуэль на картах-командах и карьера продюсера телевизионного боевого шоу альтернативных 2000-х.

Вы не управляете бойцом напрямую. Боец сражается сам, а вы как продюсер отдаёте тактические команды картами, собираете комбо и делаете эфир зрелищным. Чем выше рейтинг шоу, тем больше гонорар, фанаты и репутация.

## Запуск

Нужен Node.js 18+ (проверено на Node 24).

```bash
npm install
npm run dev        # dev-сервер: http://localhost:5173 (флаг --host открывает доступ с телефона в той же Wi-Fi сети)
npm run build      # проверка типов + production-сборка в dist/
npm run preview    # локальный просмотр production-сборки
npm run sim        # headless-симуляция сотен боёв для проверки баланса (боты idle / mash / combo)
npm run audit      # откуда берётся рейтинг шоу у разных стилей игры
npm run decks      # перебор всех 35 колод каждого бойца: сила колод и вклад каждой карты
npm run saves      # проверка загрузки сохранений Alpha 1.0 и 1.1
npm run events     # проверка системы сезонных событий (календарь, задания, жетоны, награды, сохранения)
npm run modes      # проверка режимов (Survival, Prime Challenge, Boss Fight) и отчёт по их балансу
npm run arenas     # проверка павильонов: доступность, RANDOM, декорации, одинаковый исход боя, сохранения
npm run collection # проверка «Моей коллекции» и этапов карьеры продюсера (выдача, слоты, личные награды, миграция)
npm run anims      # проверка анимаций всех бойцов и соперников (стабильность, приоритеты состояний, победы)
npm run cards      # проверка 15 новых карт (1.6.1: SECOND TAKE, кольцо FREEZE, место BARRIER, парирование), комбо, подсказок, лимитов, магазина и сохранений
npm run cardsim    # баланс новых карт: старые колоды против новых, архетипы, сложности, босс, Survival, ENERGY RUSH
npm run music      # саундтрек и зрители: 7 MP3, назначения, выравнивание громкости, затухания, точки повтора, лимиты реакций публики
npm run tutorial   # FIRST BROADCAST: кому запускается обучение, тренировочный бой, настоящий COUNTER STRIKE, отсутствие прогресса
```

Чтобы открыть игру на телефоне, запустите `npm run dev` и откройте в мобильном браузере адрес `Network:`, который выведет Vite.

## Как играть

- **Энергия** копится сама: ≈1 ед. за 1.25 с, максимум 10. Карты стоят 1–6.
- В колоде 4 карты: 3 в руке, 4-я ждёт в очереди. Сыгранная карта уходит в конец очереди.
- **Комбо**: карта с меткой «КОМБО ▸» начинает связку. Сыграйте её — вторая карта пары подсветится золотом, на неё есть 3 с (полоска «Время на комбо»). При успехе баннер покажет, какие карты сработали и какой бонус получен:
  - DASH → POWER SHOT / KNOCKOUT / CHARGED SHOT = **COUNTER STRIKE**
  - SHOCK / SYSTEM OVERLOAD → POWER SHOT / KNOCKOUT / CHARGED SHOT = **ELECTRO BLAST** (ультра-комбо)
  - SHIELD → OVERDRIVE = **IRON RUSH**
  - SMOKE → DASH = **PHANTOM STEP** (голограмма-приманка)
  - OVERDRIVE → фирменная карта = **SUPERSTAR MOVE** (ультра-комбо)
  - Alpha 1.6: ещё 20 тактических связок новых карт — например GRAVITY NET → PRESSURE MINE = **GRAVITY TRAP** («ЛОВУШКА»); полный список доступных пар показывает экран колоды
- **Красная зона**: соперник заряжает удар. DASH уклоняется, SHIELD блокирует, SHOCK прерывает.
- **DASH** в момент атаки засчитывается как идеальное уклонение: возвращает 1 энергию, а следующий залп бойца бьёт на 60% сильнее (контратака).
- **SMOKE** не только сбивает прицел соперника, но и снижает входящий урон на 30%, пока боец стоит в облаке.
- **SHIELD**, поставленный впустую (ничего не поглотил), немного снижает рейтинг: щит нужно ставить под удар.
- **Карта не сработала** — над ней появится причина: не хватает энергии (сколько ещё нужно), боец оглушён, взломан или занят.
- **Рейтинг шоу** (0–100) растёт за комбо, идеальные уклонения, блоки и прерывания, мощные попадания, разнообразие приёмов и эффектный финиш. Простой и бездействие снижают его.

## Что нового в Alpha 1.6.5 «First Broadcast»

**FIRST BROADCAST — ПЕРВЫЙ ЭФИР.** Короткое интерактивное обучение для новых игроков (~15–25 с), в студии Original Prime Arena против тренировочного робота PRIME TRAINING BOT.

1. «БОЕЦ СРАЖАЕТСЯ САМ!» → «ТЫ — ПРОДЮСЕР. ИСПОЛЬЗУЙ КАРТЫ!» — боец сам двигается и стреляет, карты пока не нажимаются.
2. «НАЖМИ DASH!» — подсвечена только DASH (остальные карты приглушены и не срабатывают), энергии хватает.
3. «ТЕПЕРЬ POWER SHOT!» — робот замирает; DASH → POWER SHOT — настоящий COUNTER STRIKE из системы комбо (в учебном бою окно комбо 30 с, чтобы новичок успел прочитать подсказку).
4. Комбо-выстрел попадает, робот замыкает и отключается (искры, гаснущие лампы, «X X» на визоре), «ГОТОВ К ЭФИРУ!», аплодисменты → обычное меню.

Ни один шаг не заканчивается по таймеру — обучение ждёт нажатия нужной карты. Кнопка «ПРОПУСТИТЬ» видна с самого начала; пауза в обучении предлагает «Пропустить обучение». Повтор — Настройки → «Пройти обучение».

- **Кому:** только новым игрокам. Обучение запускается после первого касания, если в сохранении стоит `tutorial: 'pending'`. Сохранения старых версий (без этого флага) с любым прогрессом — матчи, деньги, репутация, подписанные бойцы, покупки, этапы, рекорды режимов — получают `veteran` и обучение не видят; нетронутая карьера считается новой. Завершение и пропуск запоминаются; перезагрузка посреди обучения просто начинает его заново (до конца ничего не сохраняется). Сброс прогресса не заставляет проходить обучение повторно.
- **Ничего не засчитывается:** учебный бой не попадает в результаты, карьеру, деньги, фанатов, рейтинг, победы Classic Duel, доступ к боссу, события и режимы; колода у боя своя (DASH, POWER SHOT, SHIELD, SMOKE), колоды игрока не меняются.
- **Робот** собран на скелете и анимациях обычного бойца: стальной шлем с тёмным визором и янтарными глазами, антенна с лампой, оранжевые панели. Стреляет медленно и слабо, карт не играет (у него нет энергии), не может победить; на шаге POWER SHOT стоит на месте.

**Зрители.**
- Публика отвечает на событие через 0,45–0,8 с, а не одновременно с ним: сначала звучит удар или комбо, потом реакция.
- Аплодисменты — настоящие хлопки: десятки «зрителей», каждый хлопает в своём темпе и своим тембром (процедурный синтез, буферы готовятся один раз). Выразительный момент (COMBO, крит, идеальное уклонение, трикшот) — около 2,5 с с нарастанием и затуханием; зрелищный (ультра-комбо, KO, фаза босса) — рёв и ~3 с аплодисментов со свистом.
- Повторы: одна реакция за раз; второе эффектное действие вскоре после аплодисментов получает только выкрик (без второго раунда); баннеры трансляции дают максимум выразительную реакцию; рёв на нокаут проходит всегда. В конце боя ожидающие мелкие реакции отменяются.
- Победа: фанфара → овация ~5 с → спокойные, но слышимые аплодисменты со свистами и выкриками, пока открыт экран результатов; при выходе плавно стихают. Поражение: вздох зала, несколько вежливых хлопков, тишина.
- Фон зала: тихий гул, изредка отдельные хлопки, выкрики, лёгкая волна по трибунам; после зрелищного момента зал на несколько секунд «гудит» чуть громче. Без шипения и «морских волн».

## Что нового в Alpha 1.6.4 «Sound Polish»

Точечная полировка звука после проверки на iPhone. MP3, их назначение, сезонная музыка, звуки оружия, карт, разрушений и интерфейса не менялись.

- **Конец матча.** Музыка боя начинает затухать в момент окончания боя (KO, время, сдача) и стихает за 1,8 с по плавной кривой — раньше она играла ещё ~3–4 с замедленного финала и обрывалась за 0,7 с. Фанфара и аплодисменты звучат уже без музыки, через 3 с после результатов мягко (за 2 с) входит музыка меню. Боевая музыка после победы или поражения не возвращается — проверено для обычного боя, поражения, Boss Fight, Survival и Prime Challenge, а также при выключении музыки и уходе со вкладки во время затухания.
- **Начало боя.** Музыка появляется плавно за 1,5 с.
- **Громкость.** Треки выравниваются по среднему двух измерений: обычной громкости (LUFS) и громкости через динамик телефона (басы ниже ~250 Гц телефон почти не воспроизводит). Все семь композиций теперь в пределах 0,3 дБ друг от друга. Меню стало на ~1 дБ тише и звучит на одном уровне с боем (раньше было громче, а без выстрелов поверх казалось ещё громче). Музыка в бою ≈ −31 LUFS; эффекты в среднем на 2–2,5 дБ громче музыки, громкие моменты — на 5–10 дБ, в том числе через телефонный динамик. Пик суммы — 0,31 от полной шкалы, до клиппинга далеко.
- **Зрители.** Источник «шума моря» — фоновый шум зала: полоса шума, которую фильтр раскачивал с частотой 0,3 Гц, по 2-секундной петле, и с рейтингом шоу он вырастал почти до громкости музыки; сверху каждое событие добавляло 2–3 с широкополосного шипения. Теперь:
  - фон — тихий низкий гул полного зала (на ~20 дБ тише музыки, с рейтингом растёт не больше чем на 2,5 дБ), без раскачки, своя 9-секундная петля;
  - изредка, с паузами 7–15 с, лёгкая волна по трибунам;
  - реакции трёх уровней: короткое «о!» (обычное сильное попадание — не каждый раз), выразительное «е-е!» с хлопками (COMBO, крит, идеальное уклонение, трикшот, финт), рёв с аплодисментами и свистом (ультра-комбо, KO, фаза босса);
  - одновременно звучит только одна реакция: меньшая не накладывается на идущую, а большая мягко её прерывает; между реакциями — паузы;
  - победа — полноценные аплодисменты ~3,5 с (настоящие хлопки, а не шипение), поражение — разочарованное «у-у».

- **Повтор.** Песня звучит целиком и повторяется по точному расписанию аудио-часов, без таймеров. Пропускается только цифровая тишина в начале и в конце и неслышный хвост затухания (на 30 дБ ниже средней громкости трека). Стык сглажен на несколько миллисекунд — без щелчка и паузы. Точки повтора находятся в самом аудио, поэтому заменённый файл не требует новых чисел.
- **Переходы.** Старый трек затихает за 0,7 с, затем новый появляется за 1,2 с — два трека одновременно не звучат. Повторный запрос того же трека (смена бойца, переход между экранами меню) ничего не перезапускает. На результатах музыка боя затихает под фанфару победы или поражения, через 3 с возвращается музыка меню (она заранее декодирована).
- **Громкость.** Треки выровнены по громкости (LUFS, коэффициенты в `src/config/music.config.ts`). Меню ≈ уровню старой музыки меню; в бою музыка на ~4,5 дБ тише старой, чтобы выстрелы и карты были отчётливо сверху. Компрессор и лимитер мастера на музыку не срабатывают. Подобрано измерениями, а не на слух — при желании поправьте `MUSIC_MIX.menu` / `MUSIC_MIX.battle`.
- **Ресурсы.** Скачивается только нужный трек (музыка меню — заранее, пока открыт стартовый экран). В памяти декодирован только играющий трек (32–66 МБ), закодированных файлов хранится не больше трёх. Один музыкальный плеер на всю игру; ошибка загрузки — предупреждение в консоли, игра идёт без музыки и попробует снова при следующем запросе.
- **Настройки.** Выключатели музыки и звука работают как раньше; при выключении музыка останавливается и освобождает память. На iPhone музыка, как и эффекты, идёт через Web Audio и стартует после первого касания; в беззвучном режиме телефона она молчит вместе с эффектами.

- пока вы оглушены или взломаны и ещё 2,5 с после этого — нового контроля не будет;

**Графика**
- Персонажи собираются процедурно из десятков примитивов, запечённых в один меш на кость с вертексными цветами. Toon-шейдер с rim-светом, инвертированные контуры.
- Процедурные анимации: локомоция с поворотом таза, стрейфом и бегом спиной, переступание на месте, живое ожидание (дыхание, перенос веса, взгляды), прицеливание и жесты оружия, пружинная отдача, реакции на урон, кувырок, рывок, пируэт, подкат и телепорт, оглушение, отброс, нокаут, по три победы на бойца, моргание и мимика.
- Арена ТВ-студии: процедурный пол, неоновые ограждения, разрушаемые LED-колонки, трибуны с анимированной толпой и световыми палочками (реагирует на рейтинг), LED-табло с живыми данными, неоновые вывески, прожекторы с объёмными лучами. С Alpha 1.4 — четыре павильона (оригинальный, казино, съёмочная площадка, сезонный особняк) с интерактивными декорациями.
- VFX на пулах: частицы, вспышки выстрелов, ударные волны, молнии, энергощит, дым, аура разгона, линии телеграфа, обломки, голограмма-приманка, конфетти.
- Bloom, тени, адаптивное качество (авто, высокое, среднее, низкое) с ограничением pixel ratio.

**Мета**
- Карьера продюсера: деньги, репутация, 10 уровней, четыре этапа (ROOKIE PRODUCER → LEGENDARY PRODUCTION) с разовыми наградами, фанаты каждого бойца, контракты (Бруно с уровня 2 за $500, Ника с уровня 3 за $900, Вега с уровня 4 за $1300, Кай с уровня 4 за $1500, Рина с уровня 5 за $1800), 8 целей с наградами.
- «Моя коллекция»: все косметические награды и достижения, слоты оформления, сезонные предметы навсегда.
- Сложность «Профи» открывается с уровня 2, «Чемпион» с уровня 4.
- Награды с прозрачной разбивкой: гонорар, бонус за нокаут, рейтинг, комбо, спонсоры, фанаты, репутация.
- Режимы эфира: Classic Duel, Survival (5 волн, бонусы, рекорды), Prime Challenge (3 испытания) и Boss Fight (легендарный чемпион в три фазы) — на одном движке боя с модификаторами матча.
- Сохранение в `localStorage` с валидацией: повреждённые данные не ломают игру. Сохранения всех прошлых версий (Alpha 1.0–1.5) загружаются без потерь (`npm run saves`).

**Звук**: полностью процедурный (Web Audio), без файлов. SFX под каждое оружие и карту, реакции толпы, ТВ-стингеры, динамическая музыка (интенсивность зависит от рейтинга). Звук включается только после первого тапа; есть кнопки звука и музыки.

## Структура

```
src/
  config/      баланс, карты, бойцы, сложности, карьера, внешность, профили анимации
               и отдачи; events/themes/cosmetics.config.ts — сезоны (данные отдельно от кода);
               modes.config.ts — волны Survival, бонусы и испытания Prime Challenge;
               boss.config.ts — босс, его фазы, приёмы и награды;
               arenas.config.ts — павильоны: доступность, декорации, свет
  core/        математика, RNG, пружины
  combat/      чистая симуляция боя без DOM и WebGL: Match, CombatSystem, Abilities,
               FighterAI, CardSystem, ComboSystem, BroadcastSystem, BossDirector (фазы босса)
  render/      Three.js: Renderer, Arena (менеджер павильонов), FighterModel, FighterAnimator, VFX,
               CameraRig, BattleView, Showcase, PortraitStudio, SeasonalDecor;
               stages/ — павильоны (StageKit + Original/Casino/Backlot/HauntedStage)
  audio/       процедурный звук (AudioSystem) и плеер саундтрека из MP3 (MusicPlayer)
  meta/        SaveSystem, CareerSystem (+ careerStages — этапы карьеры), EventManager (сезонные
               события), GameModes (режимы), ArenaSelection (доступность павильонов и RANDOM),
               Collection («Моя коллекция»: владение, слоты, личные награды бойцов, NEW, достижения)
  ui/          экраны и HUD (DOM поверх canvas); viewport.ts — реальная высота экрана и поворот
  game/        Game.ts — оркестратор состояний, ThemeManager.ts — сезонное оформление
scripts/       headless-проверки: боты (bots.ts), баланс (simulate), рейтинг (rating-audit),
               колоды (deck-analysis), миграция сохранений (save-migration-check),
               сезонные события (events-check), режимы (modes-check), павильоны (arena-check),
               коллекция и этапы карьеры (collection-check), анимации (anim-check)
docs/          SEASONAL_EVENTS.md — как управлять сезонами; GAME_MODES.md — режимы и испытания;
               ARENAS.md — павильоны и как добавить новый;
               COLLECTION_AND_CAREER.md — коллекция, этапы карьеры, новые бойцы
```

## Отладочные параметры URL

`?autostart` сразу запускает бой, `?speed=4` ускоряет симуляцию. Оба нужны для автоматических проверок и в обычной игре не используются.
