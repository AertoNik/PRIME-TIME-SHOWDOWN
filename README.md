# PRIME TIME: SHOWDOWN

Первый играбельный прототип мобильной карточной дуэли. TypeScript, Phaser 3 и Vite. Все рисунки, иконки, анимации и звуки создаются локально; сервер приложения и внешние сервисы не нужны.

## Запуск

На этом Mac можно дважды нажать **START.command**: скрипт использует установленный Node.js или runtime Codex и открывает браузер. Окно Terminal нужно оставить открытым; Control+C останавливает игру.

Обычный запуск на компьютере с Node.js 20.19+ или 22.12+ и npm:

```sh
npm install
npm run dev
```

Откройте http://localhost:5173. На телефоне в той же Wi-Fi сети откройте `Network`-адрес, который напечатает Vite, например `http://192.168.1.103:5173`. При запросе macOS разрешите доступ к локальной сети. Компьютер и сервер должны оставаться включёнными. При смене сети адрес может измениться.

## Как играть

1. Выберите импульсник или дробовик. У дробовика выше точность, когда бойцы ближе друг к другу.
2. Выберите четыре из шести карт. Чтобы заменить выбранную карту, сначала нажмите на неё, затем на новую. Под сеткой появится описание.
3. Нажмите **PLAY**. После обратного отсчёта бойцы начнут двигаться и стрелять сами.
4. Нажимайте три карты внизу экрана. На ПК работают клавиши **1**, **2**, **3**. Энергия восстанавливается автоматически, максимум — 10.
5. Перед мощным выстрелом VOLT появится предупреждение. Ближе к концу подготовки примените рывок, используйте щит заранее или прервите выстрел электрошоком.
6. В случайный момент между 18-й и 26-й секундами наступает **SHOWTIME** на 6 секунд: ускоряются атаки и восстановление энергии, повышается урон обоих бойцов.
7. При нулевом здоровье — нокаут. После 75 секунд победитель определяется по оставшемуся здоровью; равные значения дают ничью.
8. **PLAY AGAIN** сразу запускает новый эфир с тем же снаряжением. Вторая кнопка позволяет изменить набор карт.

Кнопка паузы / **Escape** останавливает матч. Переход на другую вкладку автоматически ставит матч на паузу, включая вступление. Звук выключается кнопкой справа сверху.

## Карты

| Карта | Энергия | Эффект |
| --- | ---: | --- |
| Рывок | 2 | Быстрое перемещение и 1,05 сек. неуязвимости |
| Мощный выстрел | 3 | 125 урона; защита и уклонение противника учитываются |
| Щит | 2 | Снижение урона на 72% в течение 4 сек. |
| Дымовая завеса | 2 | Множитель точности противника 35% в течение 5 сек. |
| Электрошок | 3 | 35 урона, 1,8 сек. оглушения и прерывание подготовки выстрела |
| Адреналин | 3 | Скорость базовых атак ×1,85 на 5 сек. |

Порядок карт перемешивается перед матчем. Три карты находятся в руке, четвёртая — следующая. Сыгранная карта уходит в конец цикла; дубликатов в руке нет. Смена карты длится 0,52 сек. Быстрые последовательные применения показывают COMBO; дополнительный урон за комбо не начисляется.

## Проверка и сборка

```sh
npm test
npm run build
npm run preview
```

Сборка находится в `dist/`. Для просмотра нужен HTTP-сервер, открытие `index.html` через `file://` не поддерживается. Тесты проверяют цикл карт, ограничения энергии, реакцию защитных способностей на сильную атаку, тайм-аут, ничью и влияние тактики на исход на 50 воспроизводимых комбинациях оружия и seed.

## Публикация на GitHub Pages

Сайт: https://aertonik.github.io/PRIME-TIME-SHOWDOWN/

В `vite.config.ts` задан `base: '/PRIME-TIME-SHOWDOWN/'`. Workflow `.github/workflows/deploy.yml` при push в `main` выполняет `npm ci` и `npm run build`, затем публикует только содержимое `dist` через официальный Pages artifact. В настройках репозитория **Settings → Pages → Source** должен быть выбран **GitHub Actions**. Исходный `index.html` из корня репозитория напрямую публиковать нельзя: браузер не запускает исходный TypeScript.

Локальная проверка именно собранного сайта:

```sh
npm run build
npm run preview
```

Адрес предпросмотра: http://localhost:4173/PRIME-TIME-SHOWDOWN/

## Устройство прототипа

- `src/combat.ts` — симуляция боя без Phaser, с внедряемым генератором случайных чисел.
- `src/arena.ts` — сцена Phaser, процедурная арена, бойцы и ограниченные по количеству эффекты.
- `src/ui.ts`, `src/style.css` — сенсорный интерфейс, снаряжение, пауза, результаты.
- `src/audio.ts` — короткие синтезированные звуки Web Audio.
- `src/data.ts` — параметры карточек, оружие и векторные иконки.

Игровая область 450×800 масштабируется под доступный экран с учётом safe area. Аудитория обновляется на 16 Гц, бой и эффекты — до 60 FPS; обновление HUD ограничено примерно 20 Гц. Это ориентир, фактическая производительность зависит от устройства. Все способности работают, ИИ использует мощный выстрел, щит и адреналин. Графика стилизована из векторных фигур; настоящего 3D нет.

Снаряжение, звук, фанаты и монеты сохраняются только в `localStorage` этого браузера. Награды условные, покупок и экономики нет. Баланс экспериментальный: своевременная защита должна давать заметное преимущество. Сеть нужна только для установки npm-зависимостей; во время игры внешних запросов нет.
