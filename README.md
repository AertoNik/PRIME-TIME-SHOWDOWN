# PRIME TIME: SHOWDOWN — Alpha 1.3.4 «Balance Refinement»

Стилизованная мобильная браузерная 3D-игра: тактическая дуэль на картах-командах и карьера продюсера телевизионного боевого шоу альтернативных 2000-х.

Вы не управляете бойцом напрямую. Боец сражается сам, а вы как продюсер отдаёте тактические команды картами, собираете комбо и делаете эфир зрелищным. Чем выше рейтинг шоу, тем больше гонорар, фанаты и репутация.

## Запуск

Нужен Node.js 18+ (проверено на Node 24).

```bash
npm install
npm run dev        # dev-сервер: http://localhost:5173 (флаг --host открывает доступ с телефона в той же Wi-Fi сети)
npm run build      # проверка типов + production-сборка в dist/
npm run preview    # локальный просмотр production-сборки
npm run sim        # headless-симуляция сотен боёв для проверки баланса (боты idle / mash / combo)
npm run audit      # откуда берётся рейтинг шоу у разных стилей игры
npm run decks      # перебор всех 35 колод каждого бойца: сила колод и вклад каждой карты
npm run saves      # проверка загрузки сохранений Alpha 1.0 и 1.1
npm run events     # проверка системы сезонных событий (календарь, задания, жетоны, награды, сохранения)
npm run modes      # проверка режимов (Survival, Prime Challenge, Boss Fight) и отчёт по их балансу
```

Чтобы открыть игру на телефоне, запустите `npm run dev` и откройте в мобильном браузере адрес `Network:`, который выведет Vite.

## Как играть

- **Энергия** копится сама: ≈1 ед. за 1.25 с, максимум 10. Карты стоят 2–6.
- В колоде 4 карты: 3 в руке, 4-я ждёт в очереди. Сыгранная карта уходит в конец очереди.
- **Комбо**: карта с меткой «КОМБО ▸» начинает связку. Сыграйте её — вторая карта пары подсветится золотом, на неё есть 3 с (полоска «Время на комбо»). При успехе баннер покажет, какие карты сработали и какой бонус получен:
  - DASH → POWER SHOT / KNOCKOUT / CHARGED SHOT = **COUNTER STRIKE**
  - SHOCK / SYSTEM OVERLOAD → POWER SHOT / KNOCKOUT / CHARGED SHOT = **ELECTRO BLAST** (ультра-комбо)
  - SHIELD → OVERDRIVE = **IRON RUSH**
  - SMOKE → DASH = **PHANTOM STEP** (голограмма-приманка)
  - OVERDRIVE → фирменная карта = **SUPERSTAR MOVE** (ультра-комбо)
- **Красная зона**: соперник заряжает удар. DASH уклоняется, SHIELD блокирует, SHOCK прерывает.
- **DASH** в момент атаки засчитывается как идеальное уклонение: возвращает 1 энергию, а следующий залп бойца бьёт на 60% сильнее (контратака).
- **SMOKE** не только сбивает прицел соперника, но и снижает входящий урон на 30%, пока боец стоит в облаке.
- **SHIELD**, поставленный впустую (ничего не поглотил), немного снижает рейтинг: щит нужно ставить под удар.
- **Карта не сработала** — над ней появится причина: не хватает энергии (сколько ещё нужно), боец оглушён, взломан или занят.
- **Рейтинг шоу** (0–100) растёт за комбо, идеальные уклонения, блоки и прерывания, мощные попадания, разнообразие приёмов и эффектный финиш. Простой и бездействие снижают его.

## Что нового в Alpha 1.3.4 «Balance Refinement»

Небольшой балансный патч боя с боссом. Механики, оружие, модель, DIRECTOR'S CUT, три фазы, доступ (5 побед в Classic Duel) и все остальные режимы не менялись; Classic Duel, Survival и Prime Challenge работают как раньше (симуляция Classic Duel совпадает с прежней).

- **Что было не так**: STAR POWER (OVERDRIVE) у чемпиона работал почти полбоя — в 1-й фазе у него в руке были только DASH, SHIELD и OVERDRIVE. Главный урон приходился на очереди, от которых почти невозможно уйти, а щит CHAMPION GUARD затягивал бои до конца времени. Ника держала чемпиона оглушённым и взломанным почти треть боя. Бруно прижимал отступающего чемпиона к барьеру. Рэю не хватало здоровья на гонку урона.
- **Изменения** (только Boss Fight, бойцы во всех режимах прежние):
  - STAR POWER — в начале 2-й и 3-й фаз, как карта — только в финальной фазе; карты CHAMPION GUARD у чемпиона больше нет;
  - тяжёлые пули CHAMPION BURST летят медленнее (19 вместо 26): ловкий боец может уйти в сторону;
  - DIRECTOR'S CUT сильнее (+20%) и чаще (перезарядка 7 с, в финальной фазе 6 с); во время серии отброс не сбивает чемпиона — её срывают только оглушение и SYSTEM OVERLOAD;
  - «Легенда держит удар»: оглушение и SYSTEM OVERLOAD действуют на чемпиона вдвое короче (правило показано на экране подготовки);
  - отступая от бойца ближнего боя, чемпион обходит его по кругу к центру, а не упирается в барьер;
  - общий урон чемпиона ×0,96 (было ×0,86): опасность перенесена с «неизбежного» урона на приёмы, от которых можно защититься.
- **Баланс** (headless-симуляции, 300 боёв на ячейку):

  | Боец | Осознанная игра | Случайные карты |
  |---|---:|---:|
  | Рэй, колода по умолчанию | 63% | 4% |
  | Рэй, DASH/POWER SHOT/SHIELD/OVERDRIVE | 79% | 9% |
  | Бруно | 58% | 3% |
  | Ника | 69% | 0% |
  | Вега | 72% | 0% |

  Бой длится 1,3–1,8 мин, по времени заканчивается 0–4% боёв, победитель обычно заканчивает с 11–16% здоровья.

Инструкция для разработчика: [`docs/GAME_MODES.md`](docs/GAME_MODES.md), раздел «BOSS FIGHT».

- **PRIME BREAKER — CHAMPION BURST RIFLE**: тяжёлая винтовка чемпиона со своим силуэтом — тёмный графит с золотыми рейками, прицел в виде сценического прожектора с «шторками», золотой дульный тормоз-«корона», тёмно-красные вставки, светящиеся индикаторы очереди и вентиляции, маленькая метка PRIME. Свои позы: переноска у пояса, упор при стрельбе, поза с поднятой винтовкой для фирменного приёма, тяжёлая отдача.
- **CHAMPION BURST** — основная атака: короткие очереди по 3 тяжёлых выстрела с паузой ~2 с. Дальность 12 — дальше, чем у Веги (10,5) и Ники (9,5); без самонаведения и без бонуса за расстояние. Попадания весомые: вспышка, искры, лёгкий толчок камеры, свой звук.
- **DIRECTOR'S CUT** (вместо PRIME PULSE):
  - чемпион вскидывает винтовку, на экране — «DIRECTOR'S CUT!» и счётчик выстрелов;
  - три выстрела, перед каждым — своя линия прицела: сначала следит за бойцом, потом застывает, и через 0,5–0,66 с выстрел идёт ровно по ней;
  - урон наносится только внутри нарисованной линии в момент выстрела: попадание засчитывается, если центр бойца ближе к оси линии, чем её полуширина плюс половина радиуса тела. Каждый выстрел бьёт не больше одного раза;
  - третий выстрел шире и сильнее, но тоже не гарантирован; после серии чемпион открыт (ЧЕМПИОН ОТКРЫТ!), затем перезарядка;
  - ответы: DASH после того, как линия застыла (уводит из линии, неуязвимость, +1 энергия), SHIELD (поглощает урон), SHOCK или мощный удар с отбросом срывают серию. Смена фазы, нокаут и конец боя тоже обрывают её — линии исчезают сразу.
- **Фазы**: SHOW OPENING — только очереди; PRIME PRESSURE (с 65%) — STAR POWER и DIRECTOR'S CUT; FINAL BROADCAST (с 30%) — усиленный FINAL CUT: ярче линии, упреждение движения, чуть короче окна (не меньше 0,5 с), шире и сильнее третий выстрел.
- **ИИ чемпиона**: держит удобную дистанцию стрельбы, отходит рывком DASH, когда к нему подбираются вплотную, не применяет приёмы после нокаута и конца боя.
- **Доступ к BOSS FIGHT**: нужно 5 побед в Classic Duel выбранным бойцом. Бойцы, которые уже побеждали чемпиона, сохраняют доступ. На карточке режима и экране подготовки виден прогресс каждого бойца. (Уровней бойцов в игре нет, поэтому условие — победы.)
- **Баланс** (headless-симуляции, 40 боёв на ячейку, колоды по умолчанию): осознанная игра — Рэй 13% (с колодой DASH/POWER SHOT/SHIELD/OVERDRIVE — 65%), Бруно 98%, Ника 93%, Вега 65%; случайные карты — Бруно 57%, Рэй 5%, Ника и Вега 0%; без карт — 0%. Бой длится 1,5–1,8 мин, победитель обычно заканчивает с 1–19% здоровья.
- **Сохранения** версии 6: у каждого бойца отдельный счётчик побед в Classic Duel. В старых сохранениях он считается как все победы бойца минус победы над боссом (победы в Prime Challenge из 1.3–1.3.2 отделить нельзя, они засчитываются). Ключ сохранения прежний.
- Проверки: `npm run modes` — DIRECTOR'S CUT (попадание только внутри линии, промах за её краем, SHIELD, DASH после фиксации, один удар за выстрел, перезарядка, срыв SHOCK, смена фазы, нокаут, конец боя), доступ к режиму и отчёт по балансу; `npm run saves` — перенос счётчика побед.

## Что нового в Alpha 1.3 «Game Modes Expansion»

Два новых игровых режима на той же боевой системе. Обычная дуэль работает как раньше: кнопка «В БОЙ» в меню ведёт в Classic Duel. Новые режимы открываются кнопкой «Режимы эфира» под ней. Инструкция для разработчика: [`docs/GAME_MODES.md`](docs/GAME_MODES.md).

- **Экран «Режимы эфира»**: CLASSIC DUEL, SURVIVAL и PRIME CHALLENGE — правила, цель, награда и рекорды каждого режима.
- **SURVIVAL — LAST STAR STANDING**: пять дуэлей подряд одним бойцом и одной колодой.
  - Соперники идут в случайном порядке без повторов подряд, каждая волна сильнее: 1–2 — «Новичок», 3–5 — «Профи», финал с бонусом к здоровью соперника.
  - Здоровье переносится: после победы +20% (не больше максимума).
  - После каждой победы — один бонус из трёх: SECOND WIND (+30% здоровья сразу), ENERGY BOOST (+25% к энергии, до 2 раз), POWER SURGE (+12% урона, до 2 раз). Бонусы действуют только до конца попытки.
  - Поражение, ничья или сдача завершают марафон. Награда — за каждую пройденную волну (с учётом рейтинга), плюс бонус за полное прохождение и разовый бонус за первое.
  - Рекорды: лучшая волна, лучшие очки шоу (сумма рейтингов пройденных волн), полные прохождения, лучший результат каждого бойца, дата рекорда.
  - Если закрыть игру посреди марафона, при следующем запуске попытка засчитывается с уже пройденными волнами — без бесплатной победы и без повторной выплаты.
- **PRIME CHALLENGE — SPECIAL BROADCASTS**: три спецвыпуска, правила видны до старта.
  - **ENERGY RUSH** (против Зои): ваша энергия ×1,5, энергия соперника ×1,25. Цель — победа. Рекорд — больше всего комбо.
  - **HIGH STAKES** (против Краша): бой 55 секунд. Нокаут — победа; по времени победа засчитывается при перевесе здоровья от 10%. Гонорар ×1,25. Рекорд — самая быстрая победа.
  - **PRIME SPOTLIGHT** (против Декса): победа и рейтинг шоу 80+. В бою виден прогноз итогового рейтинга.
  - Награда за первое прохождение выдаётся один раз; повторы приносят обычный гонорар боя. Новые испытания добавляются в `src/config/modes.config.ts`.
- **HUD**: полоска режима под рейтингом (волна, активные бонусы или цель испытания), заставка волны / испытания перед боем, надпись режима на большом экране арены.
- **Сезонные события**: марафон засчитывается в задания и жетоны как один бой (реальные комбо всех волн суммируются), испытание — как обычный бой. Сдача и прерванная попытка ничего не дают — как и раньше.
- **Сохранения** версии 4: рекорды Survival, прогресс испытаний, отметки первых прохождений. Старые сохранения 1.0–1.2.5 загружаются без потерь.
- Проверки: `npm run modes` — правила, разовые награды, перезагрузка, события и отчёт по балансу.

- Сохранения: формат прежний (v3). В старых сохранениях Вега появляется закрытой, прогресс не теряется (`npm run saves`).

## Что нового в Alpha 1.1.1 «Mobile & Quality Patch»

Небольшое обновление качества: адаптация под разные экраны, читаемость боя, подсказки по комбо. Боевая система, бойцы, карьера и сохранения не менялись.

- **Экран**: игра занимает весь экран на телефонах любых пропорций (16:9 … 20:9) и на планшетах до 4:5; на компьютере и в горизонтальном окне — аккуратная портретная колонка (не уже 320 px). Высота берётся из реальной видимой области (учёт адресной строки мобильного браузера), учитываются вырезы, Dynamic Island и нижний индикатор (safe-area). Прокрутки страницы нет; длинные экраны прокручиваются внутри своих панелей, модальные окна — внутри себя.
- **Повёрнутый телефон**: показывается подсказка «Поверните телефон вертикально», бой автоматически ставится на паузу. Слишком низкое окно на компьютере — подсказка «Увеличьте высоту окна».
- **3D-камера**: рамка боя считается по реальной высоте HUD (верхние полосы и карты) на каждом экране и при каждом изменении размера (ResizeObserver), камера смотрит на уровень корпуса, чтобы оба бойца стояли в свободной зоне, а не под картами или панелями. Бойцы в меню и ростере вписываются в свободное место между панелями. Разрешение рендера ограничено бюджетом пикселей (планшеты и большие экраны не рендерят лишнее).
- **Боевой HUD**: мягкое затемнение за верхними полосами, крупнее числа HP, статусы под полосой здоровья — не больше трёх, по важности; подписи над бойцами не налезают друг на друга и на верхние полосы; изменения рейтинга объединяются; крупные события (комбо, нокаут) вытесняют мелкие баннеры; убраны дубли (PERFECT DODGE, пассивки, комбо соперника).
- **Подсказки по комбо**: метка «КОМБО ▸» на карте, которая начинает связку с картой в руке; золотая подсветка второй карты и полоска «Время на комбо»; баннер успешного комбо поясняет пару карт и бонус («DASH → POWER SHOT · урон ×1.5»). Всё по правилам ComboSystem.
- **Удобство**: причина над неработающей картой, защита от случайного двойного тапа, «⇄ Сменить» бойца прямо в подготовке, ссылки «Колода и сложность» / «Сменить бойца» и совет по рейтингу на экране результатов, исправлены вылезающие кнопки и тексты на узких экранах.
- **Баланс «Новичка»**: соперник стал чуть крепче (HP ×1.0 вместо ×0.95, урон ×0.95 вместо ×0.72, энергия ×0.75 вместо ×0.6), чтобы бой нельзя было выиграть совсем без карт, при этом любая активная игра по-прежнему побеждает. «Профи» и «Чемпион» не менялись.
- **Стабильность**: качество графики больше не снижается само, пока вкладка в фоне; при возвращении во вкладку обновляются тайминги, раскладка и звук (в том числе после звонка на iOS); пропущенные такты музыки не «выстреливают» разом; в фоне не тратится GPU.

## Что реализовано

**Бой**

- Хит-стоп, замедление на комбо и нокауте, тряска и «удар» камеры, вспышки.

**Бойцы**: Рэй «Флэш», Бруно «Бульдозер», Ника «Глитч», Вега «Зенит». У каждого свои статы, оружие, пассивка, фирменная карта, стиль рывка, idle и победная поза. Соперники Декс, Танк, Зои и Краш построены на тех же архетипах (Краш — с собственными поправками к статам и стилем поведения).

**Графика**
- Персонажи собираются процедурно из десятков примитивов, запечённых в один меш на кость с вертексными цветами. Toon-шейдер с rim-светом, инвертированные контуры.
- Процедурные анимации: локомоция с поворотом таза и бегом спиной, прицеливание, пружинная отдача, реакции на урон, кувырок, рывок и телепорт, оглушение, отброс, нокаут, победа, моргание и мимика.
- Арена ТВ-студии: процедурный пол, неоновые ограждения, разрушаемые LED-колонки, трибуны с анимированной толпой и световыми палочками (реагирует на рейтинг), LED-табло с живыми данными, неоновые вывески, прожекторы с объёмными лучами.
- VFX на пулах: частицы, вспышки выстрелов, ударные волны, молнии, энергощит, дым, аура разгона, линии телеграфа, обломки, голограмма-приманка, конфетти.
- Bloom, тени, адаптивное качество (авто, высокое, среднее, низкое) с ограничением pixel ratio.

**Мета**
- Карьера продюсера: деньги, репутация, 10 уровней, фанаты каждого бойца, контракты (Бруно с уровня 2 за $500, Ника с уровня 3 за $900, Вега с уровня 4 за $1300), 8 целей с наградами.
- Сложность «Профи» открывается с уровня 2, «Чемпион» с уровня 4.
- Награды с прозрачной разбивкой: гонорар, бонус за нокаут, рейтинг, комбо, спонсоры, фанаты, репутация.
- Режимы эфира: Classic Duel, Survival (5 волн, бонусы, рекорды), Prime Challenge (3 испытания) и Boss Fight (легендарный чемпион в три фазы) — на одном движке боя с модификаторами матча.
- Сохранение в `localStorage` с валидацией: повреждённые данные не ломают игру. Сохранения всех прошлых версий (Alpha 1.0–1.3) загружаются без потерь (`npm run saves`).

**Звук**: полностью процедурный (Web Audio), без файлов. SFX под каждое оружие и карту, реакции толпы, ТВ-стингеры, динамическая музыка (интенсивность зависит от рейтинга). Звук включается только после первого тапа; есть кнопки звука и музыки.

```
src/
  config/      баланс, карты, бойцы, сложности, карьера, внешность, профили анимации
               и отдачи; events/themes/cosmetics.config.ts — сезоны (данные отдельно от кода);
               modes.config.ts — волны Survival, бонусы и испытания Prime Challenge;
               boss.config.ts — босс, его фазы, приёмы и награды
  core/        математика, RNG, пружины
  combat/      чистая симуляция боя без DOM и WebGL: Match, CombatSystem, Abilities,

  render/      Three.js: Renderer, Arena, FighterModel, FighterAnimator, VFX,
               CameraRig, BattleView, Showcase, PortraitStudio, SeasonalDecor
  audio/       процедурный звук и музыка
  meta/        SaveSystem, CareerSystem, EventManager (сезонные события), GameModes (режимы)
  ui/          экраны и HUD (DOM поверх canvas); viewport.ts — реальная высота экрана и поворот
  game/        Game.ts — оркестратор состояний, ThemeManager.ts — сезонное оформление
scripts/       headless-проверки: боты (bots.ts), баланс (simulate), рейтинг (rating-audit),

docs/          SEASONAL_EVENTS.md — как управлять сезонами; GAME_MODES.md — режимы и испытания
```
