# Проверка Alpha 0.1 — 14 октября 2026

## Автоматические проверки

- Зависимости установлены через npm 10; `package-lock.json` сохранён.
- `npm run typecheck`: успешно, строгий TypeScript.
- `npm test`: **28 тестов**, 2 файла, все проходят.
- Проверены стоимость и очередь карт, регенерация энергии, движение, дистанции оружия, все 6 способностей, две комбинации, оглушение и срыв подготовки, уклонение, щит, дым, форсаж, истечение окон эффектов, SHOWTIME, победа/поражение/ничья, лимит 75 секунд, независимость повторных матчей, сохранение и повреждённые данные.
- Регрессии: проигравший боец не стреляет после нокаута; уже подготавливаемый POWER SHOT нельзя повторно потратить.
- **72 дуэли с фиксированными seed**: по 12 seed для каждого из трёх оружий, пассивный игрок и простой контроллер карт. Без карт — 0/36 побед; с решениями по картам — 19/36; SHOWTIME включился в 52/72 матчах. Это проверка работоспособности и влияния решений, а не статистика реальных игроков.
- `npm run build`: успешно, без предупреждений о размере чанков. Three.js выделен в собственный модуль (~484 КБ, ~122 КБ gzip), игровая логика и интерфейс ~45 КБ (~18 КБ gzip), CSS ~23 КБ (~6 КБ gzip).
- `npm audit` после обновления Vitest: **0 уязвимостей**.
- Сборка с `GITHUB_REPOSITORY=AertoNik/PRIME-TIME-SHOWDOWN` создаёт ссылки `/PRIME-TIME-SHOWDOWN/assets/...`; в `dist` нет исходных TypeScript-файлов.

## Браузерная проверка

Использован встроенный браузер Codex с настоящим WebGL. Проверены настольное окно, размеры viewport **390×844** и **320×568**. Это эмуляция размеров, не физические телефоны.

- Главное меню и настоящая 3D-сцена отображаются.
- Выбраны пистолет, дробовик и карабин; модель оружия и параметры обновляются.
- Комплект из четырёх карт сохраняется; после перезагрузки оружие и набор восстановлены.
- Вступление можно пропустить; повторные дуэли идут без него.
- Все шесть карт применены в разных матчах; обновляются энергия, очередь, состояния бойцов и здоровье.
- SHOCK + POWER выполнено в браузере: показано в результате как лучший момент, начислены дополнительные фанаты.
- Получен экран поражения с наградами, уроном, числом карт и временем. PLAY AGAIN запускает новый бой.
- Пауза и продолжение работают; выход с паузы оформлен как поражение.
- Ник изменён и восстановлен после перезагрузки. Переключатели звука и качества сохраняются.
- На 320×568: `innerWidth = scrollWidth = 320`, игровой контейнер 320×568, горизонтального скролла нет. Прокручиваемые страницы экипировки, карьеры и настроек сохраняют доступность кнопок.
- Production-preview открыт по **http://127.0.0.1:4187/PRIME-TIME-SHOWDOWN/**: меню, 3D и полный матч работают при base path репозитория.
- HTML, оба JavaScript-модуля, CSS и favicon в подпапке репозитория возвращают HTTP 200 с корректными MIME-типами.
- Карьера показывает накопленные фанаты, кредиты, число эфиров, урон и комбинации; после production-перезагрузки прогресс восстановлен.
- В production-странице ошибок JavaScript/WebGL не зафиксировано. В истории вкладки есть старое сообщение HMR от остановленного dev-сервера на 5173; оно не относится к production-сборке.

## Границы проверки

- Победа и ничья проверены автоматическими тестами симуляции; в ручных браузерных матчах получены поражения. Отдельный ручной просмотр экрана победы остаётся полезной проверкой перед релизом.
- Не проверены физические Android/iPhone, реальное устройство с медленной GPU, аппаратные safe areas и фактическое качество звука через динамик.
- Принудительная потеря и восстановление WebGL-контекста не вызывались; обработчики и экран восстановления реализованы.
- GitHub Actions подготовлен, загружает исключительно `dist`. Финальные правки этой проверки не отправлялись в удалённый репозиторий; публикация и живой GitHub Pages не подтверждены.
