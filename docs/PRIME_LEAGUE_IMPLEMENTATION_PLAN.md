# PRIME LEAGUE (Alpha 1.9.0) — план реализации

> Статусы: `IMPLEMENTED LOCALLY` → `TESTED LOCALLY` → `STAGING PASS` → `PUBLISHED` → `ENABLED IN PRODUCTION`. Текущее состояние — в `docs/PRIME_LEAGUE_PROGRESS.md`.

## Фаза A — фундамент и честная дуэль (критический путь)

| # | Работа | Критерий готовности |
|---|---|---|
| A1 | Детерминированная математика боя (`src/core/dmath.ts`), прогон старых тестов боя | 40/40 боёв совпадают Node ↔ goja; `sim`, `cards`, `modes` и др. зелёные |
| A2 | Режим лиги в `Match` (`cfg.league`: защитник = настоящий боец + колода + тактика; уровни; без бонусов сложности) + счётчик шагов | Симметрия: зеркальный бой RAY–RAY без карт ≈ 50/50 |
| A3 | Шесть тактик ИИ-режиссёра — профили приоритетов в `FighterAI` (только выбор карт) | Тактики различаются составом сыгранных карт; движение/меткость те же |
| A4 | Сборка `league_sim.js` + `SIM_VERSION` (генерация, проверка актуальности) | Тест падает, если код боя изменён без пересборки |
| A5 | Миграция лиги, `lib/league.js`: вступление, профиль, защита, старт/промежуточный журнал/финиш, пересчёт, RP/MMR, подбор, cron просрочки | Тесты: подделки, гонки, повторы, просрочка, версия правил |
| A6 | Конфиг лиги `src/config/league.config.ts` → серверные правила | Один источник чисел для игры и сервера |
| A7 | Балансовый симулятор `npm run league:sim` | Таблица прогресса новичка/среднего/сильного/фармера |

## Фаза B — Defense Studio и экономика

B1 слоты 1–5 с проверкой владения; B2 тактики в студии; B3 отчёт «Пока тебя не было в эфире», награды защиты с общими лимитами; B4 PRIME TOKENS (журнал), улучшения бойцов под флагом.

## Фаза C — ранги, сезон

C1 8 крупных рангов × III/II/I, PRIME CHALLENGE (3 победы до 2 поражений); C2 сезон по серверному времени, мягкий сброс при первом входе в новом сезоне, архив, эфирные очки и дорожка наград, лидерборд; C3 церемония повышения.

## Фаза D — RUSH и SQUAD

Поверх того же матча: `league_series` хранит серию; каждая дуэль — обычный `league_matches` с `series`. SQUAD: три разных бойца, победа 2 из 3, начисление один раз при закрытии серии.

## Фаза E — интерфейс, полировка, выпуск

Лобби (ИГРАТЬ / РЕЙТИНГ / МОЯ ЗАЩИТА / НАГРАДЫ / ИСТОРИЯ), афиша дуэли, итог, студия, RU/EN, 375 px; `docs/ALPHA_1_9_0_STAGING_PLAN.md`, `docs/ALPHA_1_9_0_RELEASE_PLAN.md`; серверный архив.

## Риски

1. **Нагрузка пересчёта** (≈1 с на бой в goja) — см. архитектуру, раздел 6.
2. **Помощь программы при игре** — смягчается, но не исключается (архитектура, раздел 2).
3. **Владение из карьеры** — доверие к сохранению PRIME CLOUD; сила ограничена каталогом.
4. **Малая аудитория** — системные участники PRIME NETWORK: честно подписаны, вне таблицы игроков, RP от них ограничен (предложение, требует утверждения).
5. **Изменение математики боя** затрагивает все режимы на уровне последнего бита — проверяется существующими тестами боя.
