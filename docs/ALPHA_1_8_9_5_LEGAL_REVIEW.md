> Подготовлено 29.10.2026 при локальной разработке. **Это не юридическое заключение.** Источники проверены поиском 29.10.2026. Где первоисточник не открывался напрямую, это помечено. Окончательное включение — только после проверки юристом и снятия блокеров из раздела 3.

## 2. Что технически гарантировано (без юридических оценок)

- **Возраст.** PRIME ID младше 14 лет не создаётся: форма и сервер решают одинаково, тест `public:test`. 14–17 лет — только по явной серверной настройке. Возрастную группу нельзя поднять запросом к API: записи `consents` пишут только хуки, повторно указать возраст нельзя.
- **Покупки.** Право покупки проверяет **сервер** — одинаково для нового заказа, получения страницы оплаты и повторной попытки (`checkout.js`, `minorRefusal`). Без `PRIME_SHOP_MINORS=on` **и** без отметки `minors: true` у действующей редакции оферты покупатель младше 18 получает `adult_only`.
- **Согласия.** Галочки «родитель согласен» нет и не будет. Принятие оферты записывается сервером с номером редакции и SHA-256 текста.
- **Цены.** Фиксированные, из серверного каталога (49 / 99 / 149 ₽). Лутбоксов, подписок и платной валюты нет.

## 3. Блокеры перед включением

**Перед публичной регистрацией с 14 лет** (`PRIME_REGISTRATION=public` + `PRIME_AGE_RULES=RU:14`):
- **Б-1** — заключение юриста о самостоятельном согласии 14–17 на обработку ПД (или о необходимой процедуре законного представителя).
- **Р-1** — возрастная категория игры по 436-ФЗ.
- Технически: на PRODUCTION должна работать настоящая почта (`PRIME_MAIL_MODE=smtp`). Без неё сервер сам оставит регистрацию закрытой.

**Перед покупками 14–17** (`PRIME_SHOP_MINORS=on` + оферта ред. 3 с `minors: true`):
- Б-1, Б-2, Б-3 и юридическая оценка ст. 26/28/175 ГК для этих сумм и лимитов.
- Утверждённый и опубликованный текст оферты ред. 3 (черновик: `docs/legal-drafts/MINORS_PURCHASES_R3_DRAFT.md`), затем `legal:release` и запись SHA-256 в `offer.config.ts` с `minors: true`.

До снятия блокеров покупки остаются только для 18+, как сейчас. Регистрация остаётся такой, какую задаёт PRODUCTION.
