# Alpha 1.9.1 PREMIUM VISUAL UPDATE — отчёт о визуальной полировке

> 30.10.2026. Только клиент. STAGING, PRODUCTION, GitHub не менялись. Версия клиента `1.9.1-alpha` (`ALPHA 1.9.1 · PRIME LEAGUE`). Скриншоты — `preview-screens/1.9.1/` (`before-*` / `after-*`).

## 1. «В БОЙ!» и переключатель (P0)

- **Первое нажатие** открывает окно «Выберите эфир»: КАРЬЕРА и PRIME LEAGUE.
  - Окно показывается, только если лига доступна (`g.league.access() !== 'off'`).
  - Для гостя и неподтверждённой почты под карточками есть подсказка.
  - Escape закрывает окно, фокус ставится на первую карточку.
- **Память выбора:** ключ `primetime-fight-entry-v2` в localStorage, только явный выбор.
  - Явный выбор — карточка в окне или переключатель в шапке.
  - Старый ключ v1 (портился автозаписью) удаляется при первом явном выборе.
- **Лига выключена или нет связи:** сразу карьера.
  - При недоступном сервере — сообщение «PRIME NETWORK не отвечает — PRIME LEAGUE откроется, когда связь вернётся».
  - Выбор при этом не запоминается.
- **Переключатель «КАРЬЕРА | PRIME LEAGUE»** — под шапкой обоих экранов, высота 44 px, `role="tab"`.
- Скриншоты: `after-fight-entry-safe-393.jpg`, `after-league-safe-393.jpg`.

## 2. PRIME LEAGUE

| Вкладка | Что стало |
|---|---|
| Шапка | «PRIME LEAGUE» + знак ON AIR, переключатель эфира |
| Вкладки | ИГРАТЬ / РЕЙТИНГ / ЗАЩИТА / НАГРАДЫ / ИСТОРИЯ: иконка + подпись, точка-счётчик у ЗАЩИТЫ; без обрезки на 320 px |
| ИГРАТЬ | Колода — настоящие карты карьеры (цвет, иконка, стоимость); редактор колоды — те же карты, невыбранные приглушены; SQUAD / RUSH — эмблема и чипы правил |
| ЗАЩИТА | Карты в слотах, пустое состояние со знаком, «ДОБАВИТЬ БОЙЦА» — заголовок над лентой |
| НАГРАДЫ | «Путь эфира · сезон N»: шкала до следующей ступени, узел на ступень (монета PRIME TOKENS / корона титула / эмблема сезона), «Получено» / «Забрать» (свечение) / «ещё N»; карточка PRIME TOKENS с честным текстом (копятся, тратить пока нельзя, не продаются) |
| ИСТОРИЯ | Лента атак: бейдж ПОБЕДА / ПОРАЖЕНИЕ / НИЧЬЯ / АННУЛИРОВАН + способ, аватар соперника (`producerSVG` / PRIME NETWORK), бойцы «X vs Y», RP и жетоны; защита — боец, тактика, кто атаковал, «RP не меняется»; прошлые сезоны — эмблема ранга |
| Пустые состояния | Рейтинг, история, защита — знак, одна строка смысла и действие, ведущее во вкладку |

- Скриншоты: `after-league-play-375.jpg`, `after-league-modes-375.jpg`, `after-league-rewards-375.jpg`, `after-league-history-375.jpg`, `after-league-history-empty-375.jpg`.
