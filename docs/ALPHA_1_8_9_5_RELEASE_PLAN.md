## 3. Совместимость при раздельном обновлении

- **Новый сервер + старый клиент.** Вход, PRIME CLOUD и покупки работают. Минимальный возраст 14 игра берёт из `/api/prime/config`. Политика v5 записывается с номером 5, пока сайт ещё показывает текст v4 — окно в минуты между шагами 5 и 6. Это уведомление, а не согласие.
- **Новый клиент + старый сервер.** Работает. Старый сервер сам решает возраст по прежним правилам. Арена постоянная — это только клиент.
- **Версии документов.** Обязательные документы (Соглашение 4, Согласие 3) не меняются, поэтому ни один клиент не получит `legal_outdated`. Меняется только уведомление «Политика» (4 → 5, без повторного принятия) — окно несоответствия текста и номера минимально при порядке «сервер, затем сразу клиент».
- **Занятый email.** Старый клиент получает обычный успешный ответ и показывает «подтвердите email» — как и новый.
- Поэтому **сервер первым, клиент сразу за ним**.
