# Режимы эфира PRIME TIME: SHOWDOWN (Alpha 1.3 – 1.5)

Как устроены SURVIVAL и PRIME CHALLENGE и как их настраивать. Почти всё меняется в одном файле — `src/config/modes.config.ts`.

| Файл | Что в нём |
|---|---|
| `src/config/modes.config.ts` | Волны Survival, лечение, бонусы, награды; список испытаний Prime Challenge |
| `src/meta/GameModes.ts` | Правила: ход марафона, бонусы, проверка испытаний, рекорды, разовые награды |
| `src/combat/Match.ts` | `MatchMods` — модификаторы одного боя (время, энергия, здоровье, урон) |
| `src/ui/screens/ModesScreen.ts` | Экран «Режимы эфира» |
| `src/ui/screens/SurvivalScreen.ts` | Перерыв между волнами (бонус) и итог марафона |

Все режимы используют один и тот же движок боя. Отличия передаются через `MatchMods` и живут только внутри одного матча, поэтому после выхода из режима ничего не переносится в обычную дуэль.

**Павильоны (Alpha 1.4).** Каждый режим идёт в выбранном павильоне (экран подготовки → «Павильон эфира»): ORIGINAL PRIME ARENA, LUXURY CASINO SET, PRIME MOVIE BACKLOT, сезонный HAUNTED PRIME SET или случайный. Павильон меняет только оформление — правила режимов, баланс и размеры арены одинаковы:

- **Survival** — павильон выбирается при старте марафона (RANDOM — тоже один раз) и хранится в забеге (`SurvivalRun.arena`): все волны идут в нём, даже если игрок поменяет выбор между волнами. Если забег был в сезонном павильоне, а сезон закончился, следующие волны идут в оригинальной студии;
- **Prime Challenge** — правила испытаний от павильона не зависят;
- **Boss Fight** — поверх выбранного павильона чемпион ставит своё оформление: LEGENDARY SHOWDOWN — CHAMPIONSHIP EDITION, а во время Halloween Premiere — HALLOWEEN SPECIAL (фиолетовый и оранжевый свет, тыквы, праздничные экраны и баннеры, своя карточка выхода чемпиона).

Подробно и как добавить павильон: [`docs/ARENAS.md`](ARENAS.md).

## 1. SURVIVAL

Блок `SURVIVAL` в `modes.config.ts`:

```ts
waves: [
  { difficulty: 'rookie', hpMult: 0.85, dmgMult: 0.9, reward: { money: 150, fans: 130, rep: 8 } },
  ...
],
healBetween: 0.2,      // лечение после победы (доля максимума)
ratingMoney: 1.8,      // $ за каждое очко рейтинга пройденной волны
completion: { ... },   // бонус за все 5 волн
firstClear: { ... },   // разовый бонус за первое полное прохождение
participation: { ... },// утешительный гонорар, если не пройдена ни одна волна
```

- `difficulty` — уровень ИИ соперника (`rookie`, `pro`, `champion`).
- `hpMult` / `dmgMult` — дополнительные множители здоровья и урона соперника поверх сложности.
- Количество волн = длина массива `waves`.
- Соперники выбираются из всех ИИ-противников (`RIVAL_ORDER` в `fighters.ts`) в случайном порядке, один и тот же соперник не выходит два раза подряд.

### Бонусы между волнами

Блок `PERKS`: `value` — сила эффекта, `maxStacks` — сколько раз можно взять за попытку.

| Бонус | Эффект |
|---|---|
| SECOND WIND | сразу лечит `value` (0.3 = 30%) |
| ENERGY BOOST | энергия копится быстрее на `value` за каждый взятый раз |
| POWER SURGE | урон бойца больше на `value` за каждый взятый раз |

### Что происходит с попыткой

- После старта и после каждой волны попытка записывается в сохранение (`modes.survival.active`).
- Награда выдаётся **один раз** при завершении: поражение, ничья, сдача, «Завершить марафон» или пятая победа.
- Если игру закрыть посреди марафона, при следующем запуске попытка засчитывается с уже пройденными волнами и показывается сообщение «Марафон прерван». Повторить волну перезагрузкой нельзя.
- Сезонное событие получает весь марафон как **один** бой: победа — только за полное прохождение, рейтинг — средний по волнам, комбо и идеальные реакции — сумма всех волн. Сдача и прерванная попытка событию не засчитываются.

## 2. PRIME CHALLENGE

Каждое испытание — объект в массиве `CHALLENGES`:

```ts
{
  id: 'spotlight',                 // не менять после публикации: по нему хранится прогресс
  title: 'PRIME SPOTLIGHT',
  quote: 'Одной победы мало...',   // слоган на карточке
  rules: ['...', '...'],           // правила, которые игрок видит до старта
  rival: 'dex',                    // соперник
  mods: { duration: 55, energyMult: 1.5, rivalEnergyMult: 1.25 },  // модификаторы боя
  goal: { win: true, minRating: 80, timeUpMargin: 0.1 },           // условие прохождения
  goalShort: 'ПОБЕДА + РЕЙТИНГ 80', // коротко для HUD и списка
  hudTag: 'SPOTLIGHT',             // короткое имя в полоске HUD
  record: 'rating',                // рекорд: 'combos' | 'fastest' | 'rating'
  moneyMult: 1,                    // множитель гонорара за бой
  firstClear: { money: 450, rep: 35 },  // разовая награда за первое прохождение
  icon: 'spotlight',               // иконка: 'energy_rush' | 'high_stakes' | 'spotlight'
}
```

Условия `goal` (можно сочетать):

| Поле | Значение |
|---|---|
| `win: true` | нужна победа (всегда) |
| `minRating` | итоговый рейтинг шоу не ниже значения |
| `timeUpMargin` | если бой закончился по времени, нужен перевес здоровья не меньше этой доли |

### Как добавить новое испытание

1. Скопируйте объект в `CHALLENGES` и задайте новый `id`.
2. Поменяйте тексты, соперника, `mods`, `goal` и награды.
3. Проверьте: `npm run modes` (там же отчёт, как часто испытание проходят боты) и `npm run build`.

Экран режимов, подготовка, HUD и итоговый экран подхватят испытание автоматически.

## 3. BOSS FIGHT (Alpha 1.3.1, переработка 1.3.3, баланс 1.3.4)

| Файл | Что в нём |
|---|---|
| `src/config/boss.config.ts` | Босс: фазы, приёмы, ИИ, длительность, доступ, награды; `CUT_P3` — усиленный DIRECTOR'S CUT финальной фазы |
| `src/config/balance.ts` (`CARD_TUNING.directors_cut`) | Базовые числа DIRECTOR'S CUT (фаза 2) и их описание (`CutTuning`) |
| `src/config/fighters.ts` (`RIVALS.vale`) | Здоровье, CHAMPION BURST (`mods.attack`), анимации |
| `src/combat/Abilities.ts` | DIRECTOR'S CUT: `updateCut`, `fireCut`, `inCutLane` (проверка попадания), `cancelCut` |
| `src/combat/BossDirector.ts` | Смена фаз по здоровью, STAR POWER, обрыв серии при смене фазы |
| `src/render/FighterModel.ts` / `FighterAnimator.ts` | Винтовка PRIME BREAKER и позы |
| `src/render/VFX.ts` (`CutLane`) | Линия прицела: рисуется из состояния симуляции каждый кадр |
| `src/meta/GameModes.ts` (`bossAccess`) | Доступ к режиму |
| `src/config/looks.ts` (`vale`) | Внешность |
| `src/config/themes.config.ts` (`champion`) | Чемпионская версия арены |

Фаза задаётся объектом в `phases`:

```ts
{ n: 2, title: 'PRIME PRESSURE', at: 0.65,              // начинается, когда у босса 65% здоровья
  deck: ['dash', 'directors_cut', 'charged_shot'],     // его карты в этой фазе (OVERDRIVE в колоде = STAR POWER по желанию ИИ)
  behavior: { ..., holdRange: 7 },                       // характер ИИ; holdRange — дистанция, которую он держит
  energyMult: 1.1, energyBonus: 2,                      // скорость энергии и бонус при входе
  starPower: 4.5,                                       // секунды разгона OVERDRIVE при входе (0 = нет)
  cut: CUT_P3,                                          // свои числа DIRECTOR'S CUT (необязательно)
  spots: [...] }                                        // цвета прожекторов арены
```

### CHAMPION BURST

Обычная атака босса — `RIVALS.vale.mods.attack`: `burst: { count: 3, gap }` (очередь), `interval` (пауза между очередями), `damage`, `speed`, `range`. Самонаведения нет (`homing: 0`), урон не растёт с расстоянием (`falloff: 1`).

### DIRECTOR'S CUT

Числа — `CutTuning` (массивы — по одному значению на каждый из трёх выстрелов):

| Поле | Значение |
|---|---|
| `prep` | поза с поднятой винтовкой и «DIRECTOR'S CUT!» перед первой линией |
| `aim[i]` | сколько линия следит за целью |
| `lock[i]` | время от фиксации линии до выстрела — окно для DASH / SHIELD (не делайте меньше 0,5 с) |
| `gap` | пауза после выстрела до следующей линии |
| `halfWidth[i]`, `length[i]` | размер линии; ровно этот прямоугольник рисуется на полу |
| `damage[i]`, `knockback[i]`, `stun[i]` | сила выстрела (у первых двух нет оглушения — нельзя «запереть» игрока в серии) |
| `lead` | на сколько секунд линия при фиксации упреждает движение цели |
| `recover`, `cooldown` | окно после серии и перезарядка |

Честность:
- Попадание проверяется один раз в момент выстрела, по тому же прямоугольнику, что нарисован: от босса, по зафиксированному направлению, длина до барьера. Боец получает урон, если его центр ближе к оси, чем `halfWidth` + половина радиуса тела.
- DASH во время фиксации даёт неуязвимость и уводит в сторону от линии; SHIELD поглощает урон (идеальный блок); SHOCK, SYSTEM OVERLOAD или удар с отбросом срывают серию.
- Смена фазы, нокаут любой из сторон и конец боя обрывают серию (`cancelCut`), линии исчезают в тот же кадр.

### Стойкость чемпиона (1.3.4)

`poise: { stunMult, glitchMult }` в `boss.config.ts` — во сколько раз короче на боссе действуют оглушения (SHOCK, KNOCKOUT, удар о барьер) и SYSTEM OVERLOAD. Срывать DIRECTOR'S CUT они продолжают. Во время DIRECTOR'S CUT отброс на чемпиона не действует (`CombatSystem.applyHit`). Правило написано на экране подготовки — при изменении чисел поправьте текст в `PrepScreen.ts`.

### Доступ

`unlock: { classicWins: 5 }` — нужно столько побед в Classic Duel выбранным бойцом (`FighterProgress.classicWins`). Боец, который уже побеждал чемпиона (`modes.boss[id].winsByFighter`), сохраняет доступ. Проверка — `GameModes.bossAccess`, её используют карточка режима, экран подготовки и `Game.startBoss`.

### Остальное

- Сила босса: `RIVALS.vale.mods.hpMult` (здоровье) и `ai.dmgMult` (урон всех его атак) в `boss.config.ts`. После изменений запустите `npm run modes` — там отчёт по каждому бойцу: процент побед, длительность, полученный урон, сколько выстрелов DIRECTOR'S CUT попало, уклонено, заблокировано и прошло мимо. Число боёв в ячейке — аргумент: `npm run modes -- 40`.
- SPOTLIGHT SHOT (фазы 2–3) — обычная карта CHARGED SHOT с красной зоной (`ai.telegraphMult` — её длительность).
- Победа только нокаутом (`timeUpRule: 'rival'`): если время вышло, титул остаётся у чемпиона.
- Чемпионская арена (`champion` в `themes.config.ts`) включается только на бой с боссом и экран итогов; потом возвращается тема текущего сезона.
- Награды: `rewards.moneyMult` — множитель гонорара каждого боя, `rewards.firstWin` — разовая награда за первую победу (деньги, фанаты, репутация и косметический титул). Отметка `firstWinAt` сохраняется вместе с выплатой, повторно её получить нельзя.
- Сохранения: `modes.boss[id]` — попытки, победы, первая победа, лучшее время и рейтинг, лучшая фаза, минимум здоровья чемпиона, победы каждого бойца, история последних 10 боёв.

## 4. Награды и экономика

- Новых валют нет: деньги, фанаты и репутация продюсера.
- Alpha 1.5: все режимы доступны новым бойцам — Каю и Рине (их фирменные карты работают и против Виктора; против босса сила новичков проверена `npm run modes`, сам босс не менялся). Рекорды режимов засчитываются в этапы карьеры продюсера: пройденный Survival, пройденные испытания Prime Challenge и победа над Виктором — условия PRIME TIME STAR и LEGENDARY PRODUCTION (`src/config/career.ts`, `CAREER_STAGES`). Сами режимы ничего дополнительно не выплачивают: награду этапа игрок забирает в «Карьере». Титул за первую победу над Виктором хранится в «Моей коллекции» как награда Boss Fight.
- Бой испытания оплачивается как обычный бой (с `moneyMult`) и засчитывается в карьеру, но **не меняет** следующего соперника обычной дуэли.
- Награда за первое прохождение испытания и за первый полный марафон сохраняется вместе с отметкой о выплате — повторно её получить нельзя, в том числе после перезагрузки.

## 5. Сохранения

Версия сохранения 8 (с Alpha 1.5: новые бойцы, отметки «просмотрено» в коллекции `cosmetics.seen`, полученные награды этапов карьеры `careerClaimed`; с Alpha 1.4 — выбранный павильон `arena` и павильон текущего марафона `modes.survival.active.arena`), ключ прежний. В 1.3.3 у каждого бойца появился счётчик побед в Classic Duel (`fighters[id].classicWins`, доступ к BOSS FIGHT). В старых сохранениях он считается как все победы бойца минус его победы над боссом. Данные режимов — блок `modes` (`boss` — см. раздел 3):

- `modes.survival` — попытки, полные прохождения, лучшая волна и очки, лучший результат каждого бойца, дата рекорда, отметка разового бонуса, текущая попытка;
- `modes.challenges[id]` — попытки, прохождения, дата первого прохождения, рекорд.

Старые сохранения получают пустые рекорды, остальное не меняется.

## 6. Проверки

```bash
npm run modes
```

Правила режимов, разовые награды, перезагрузка посреди марафона, сезонные события, сохранения, DIRECTOR'S CUT, доступ к BOSS FIGHT и отчёт по балансу. Без отчёта по балансу (быстрее): `npm run modes -- 0`.

```bash
npm run build
```
