## 3. Порядок выпуска (следующий этап, не сейчас)

1. Отчёт STAGING и решение владельца.
2. В рабочей папке:
   - `npm run build`;
   - проверки `league`, `payments`, `checkout`, `shop`, `primeid`, `cloud:test`, `public:test`.
3. `npm run publish:sync`: сначала пробный прогон и проверка diff, затем `--apply`.
4. Коммит и push в папке публикации, затем зелёный GitHub Actions.
5. Проверки на сайте (только чтение и вход владельца):
   - подпись «ALPHA 1.9.1»;
   - «В БОЙ!» → окно выбора;
   - вкладки лиги, коллекция;
   - `prime-shop status` — live, без изменений.
6. Наблюдение в `_logs`: `replay differ` должен отсутствовать, 429 и 5xx — на прежнем уровне.
