# Alpha 1.9.1 PREMIUM VISUAL UPDATE — готовность к выпуску

> 30.10.2026. Основание — `docs/ALPHA_1_9_1_STAGING_REPORT.md`. **Ничего не выпущено:** GitHub, сайт и PRODUCTION не менялись. Выпуск — только отдельным решением владельца.

## Заключение: **READY FOR PRODUCTION REVIEW**

Клиент `1.9.1-alpha` можно **предложить владельцу** к выпуску через GitHub (`npm run publish:sync`) после изучения отчёта. Сервер обновлять не нужно.

## Основания

1. **Против настоящего STAGING пройдены V1, V2, V4, V5, V6, V8, V9, V10, V13** — в интерфейсе и через API.
   - V3 пройден в UI для гостя и для выключенной лиги, для неподтверждённого аккаунта — через API.
   - V7 пройден через API.
2. **Совместимость клиента 1.9.1 и сервера 1.9.0:**
   - `SIM_VERSION` `76236bbb2e281ec4` одинаков;
   - 5 дуэлей лиги: хэш клиента = хэш сервера, `replay differ` 0;
   - схема сохранений 12; сохранение владельца после клиента 1.9.1 — та же карьера;
   - маршруты API не менялись.
3. **Реальные функции не затронуты:** платежи только в тестовом режиме STAGING (`IsTest=1`), оферта № 3 и юридические тексты не менялись, PRIME CLOUD, DAILY и PRIME ID работают.
4. **Критичных визуальных, навигационных и клиент-серверных дефектов нет:**
   - нет неправильных картинок купленных эффектов;
   - нет повторных наград (повтор → `duplicate`, одна выплата);
   - нет ложной «ПОБЕДЫ» до ответа сервера.
5. **Единственный найденный дефект** — заморозки от прогрева шейдеров. Он исправлен удалением прогрева: поведение вернулось к 1.9.0.
6. **Регресс зелёный:** 16 наборов, сборка и typecheck.
7. **STAGING восстановлен:** env побайтно = исходному, Mailpit остановлен, лига выключена, `invite_only`. PRODUCTION не менялся.

## Что владельцу проверить самому (после выпуска или раньше на STAGING)

- **iPhone:** Safari и PWA с домашнего экрана — вырез, нижний индикатор, «перетаскивание» приложения на краю списков; плюс Android.
- **Экраны, не открытые в UI:** неподтверждённый PRIME ID и совсем новый профиль в лиге — нужен отдельный тестовый вход.
- **Производительность:** цель «без рывков при первых эффектах» **не достигнута**. В первом бою сессии остаются 1–3 подёргивания по 100–300 мс, как в 1.9.0. Получено снижение draw calls на ~16%.
- **Мелкие зоны касания старых экранов:** вкладки коллекции, фильтры магазина, кнопки профиля. Они не менялись в 1.9.1; кандидат на следующую версию.
