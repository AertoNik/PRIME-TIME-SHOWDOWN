# Павильоны (арены) PRIME TIME: SHOWDOWN — Alpha 1.4 «New Stages»

Каждая арена — это **павильон телестудии**, который канал построил для своего шоу. Павильоны отличаются только оформлением: размеры поля, барьеры, точки появления бойцов, камера, ИИ, правила и баланс везде одинаковы. Симуляция боя не знает, как выглядит павильон: декорации влияют только на картинку и звук (`npm run arenas` проверяет, что один и тот же бой с одним зерном заканчивается одинаково в любом павильоне).

| id | Павильон | Шоу | Доступность | Интерактивные декорации |
|---|---|---|---|---|
| `original` | ORIGINAL PRIME ARENA | PRIME TIME: SHOWDOWN | постоянный | LED-колонки на бортах (ломаются и восстанавливаются, как раньше) |
| `casino` | LUXURY CASINO SET | HIGH ROLLER SHOWDOWN | постоянный | стопки фишек (рассыпаются), неоновая вывеска HIGH ROLLER (мигает, частично гаснет, искрит), рулетки (раскручиваются от попаданий) |
| `backlot` | PRIME MOVIE BACKLOT | ACTION TAKE ONE | постоянный | фанерные стены (ломаются и открывают каркас), студийные прожекторы (качаются, мигают, после 3 попаданий повреждены), ящики, хлопушка |
| `haunted` | HAUNTED PRIME SET | MIDNIGHT BROADCAST | сезонный: Halloween Premiere | тыквы (лопаются: оранжевые осколки и фиолетовый дым), надгробия (трескаются, затем падают), фонари (гаснут и наклоняются), ворота с туман-машиной (выпускают туман, вывеска мигает, взлетают летучие мыши) |

## Где что лежит

```
src/config/arenas.config.ts    данные павильонов: название, описание, доступность, подпись эфира,
                               декорации (тип, место, прочность), свет, цвета
src/meta/ArenaSelection.ts     доступность, проверка сохранённого выбора, RANDOM
src/render/Arena.ts            менеджер павильонов: строит/удаляет павильон, общие экраны и табло,
                               сезонный декор (SeasonalDecor) и смешивание света с темой
src/render/stages/StageKit.ts  базовый класс Stage и общие инструменты (пол, барьер, прожекторы,
                               толпа, осколки, неон)
src/render/stages/*Stage.ts    сами павильоны: OriginalStage, CasinoStage, BacklotStage, HauntedStage
src/ui/arenaArt.ts             SVG-превью для экрана выбора
scripts/arena-check.ts         проверки (npm run arenas)
```

## Как работает выбор

- Игрок выбирает павильон на экране подготовки (кнопка «Павильон эфира»): карточки с превью, типом (постоянный / сезонный), доступностью и кнопкой выбора, плюс **СЛУЧАЙНЫЙ ПАВИЛЬОН** (RANDOM ARENA).
- Выбор хранится в сохранении по id (`save.arena`: `'original' | 'casino' | 'backlot' | 'haunted' | 'random'`). Схема v7; старые сохранения получают `'original'`, неизвестный id → `'original'`.
- Сезонный павильон открыт, пока активна тема его сезона (`events.themeId`): по календарю события или в режиме разработчика (`npm run dev` с `?event=halloween-2026`). Когда сезон заканчивается, сохранённый выбор `haunted` автоматически становится `original`.
- RANDOM выбирает только среди открытых павильонов — перед каждым боем (Survival: один раз на марафон).
- В меню за бойцом виден выбранный павильон (живое превью).

| Режим | Павильон |
|---|---|
| Classic Duel | выбранный (или случайный) |
| Survival | выбирается при старте марафона и сохраняется в забеге (`SurvivalRun.arena`) — все 5 волн в одном павильоне, даже если игрок поменяет выбор между волнами |
| Prime Challenge | выбранный; правила испытаний от павильона не зависят |
| Boss Fight | выбранный, поверх него — оформление LEGENDARY SHOWDOWN: CHAMPIONSHIP EDITION, во время Halloween Premiere — HALLOWEEN SPECIAL |

Слои оформления: **павильон** (свой пол, задник, свет, декорации) → **Boss Fight** (баннеры, пилоны, золото) → **сезон** (тыквы, фиолетовый и оранжевый свет, праздничные экраны). При смене режима или сезона предыдущий слой полностью удаляется (`SeasonalDecor.dispose`), поверх павильона никогда не остаются чужие объекты.

## Правила для декораций

- Только визуальный отклик: декорации **не наносят урон**, не мешают движению и выстрелам, не дают наград и не влияют на рейтинг шоу. Никакой физики: обломки летят по простой баллистике (`Pieces` в StageKit) и лежат на полу.
- Реагируют только на реальные попадания: снаряды, долетевшие до барьера (`CombatSystem.updateProjectiles` → `Match.hitProps`), и концы линий DIRECTOR'S CUT.
- Все декорации стоят **за барьером** (вне поля боя). Чтобы они реагировали в обычных боях, их ставят в местах, куда чаще всего прилетают промахи: северный борт, северные углы, боковые борта.
- Прочность конечна: `hp` попаданий до поломки; `respawn: 0` — сломанная декорация остаётся сломанной до конца боя (никаких бесконечных повторов), `reactive: true` + `cooldown` — декорация только реагирует (рулетка, прожектор, туман) и не ломается.
- Каждый новый бой и каждая волна Survival начинаются с целыми декорациями (`Stage.resetProps`).
- Режим «Камера: без тряски / меньше движения» и системная настройка `prefers-reduced-motion` успокаивают анимации павильона (качание, рулетки, летучие мыши, быстрое мигание).

## Как добавить новый павильон

1. **Данные** — `src/config/arenas.config.ts`:
   - добавьте id в тип `ArenaId` и в `ARENA_ORDER`;
   - добавьте запись в `ARENAS`: `name`, `show`, `description` (по-русски, 1–2 предложения), `availability` (`{ kind: 'permanent' }` или `{ kind: 'seasonal', themeId: 'halloween', event: 'Halloween Premiere' }`), `caption` (`'NEXT BROADCAST — …'`), `props`, `lighting`, `themeTint` (насколько тема сезона / Boss Fight перекрашивает свет: 0 — никак, 1 — полностью), `colors`;
   - декорации: `{ kind, x, z, hp, respawn, radius?, reactive?, cooldown? }`. Координаты — за барьером (`|x| > ARENA.halfX` или `|z| > ARENA.halfZ`); удобно брать константы `W`, `N`, `CX`, `CZ` из файла. Новый тип декорации добавьте в `PropKind`.
2. **Павильон** — новый файл `src/render/stages/MyStage.ts`, класс `extends Stage`:
   - пол той же площади: `floorCanvas()` + `floorMesh()` (размер `FLOOR_HX × FLOOR_HZ`), барьер по `ARENA.wallX / wallZ / wallCorner` (`ringShape` + `flatExtrude`) — их размеры менять нельзя;
   - задник и экраны: большой экран и LED-табло берут общие текстуры `this.sh.screenTex` / `this.sh.boardTex` (их рисует Arena, павильон их не удаляет);
   - `layout: DecorLayout` — точки для сезонного декора (тыквы, ёлки, баннеры Boss Fight, летучие мыши). Точки не должны совпадать с вашими декорациями;
   - `propHit(i, hp, heavy, x, z)`, `propBreak(i, x, z)`, `resetProps()` — индексы совпадают с порядком `props` в конфиге; эффекты через `this.vfx` (может быть `null`);
   - `applyTheme(theme, isDefault)` и `setSpots(colors)` — перекраска прожекторов и вывесок для сезона / Boss Fight;
   - `update(dt, excite, boost)` — анимации; учитывайте `this.motion` (0..1) и `this.low` (низкое качество);
   - производительность: повторяющиеся объекты — `InstancedMesh` или `merge()` в один меш, без лишних источников света (свет студии общий), частицы — только через пулы VFX. `Stage.dispose()` сам удаляет геометрию, материалы и текстуры группы.
3. **Регистрация** — `src/render/Arena.ts`, таблица `STAGE_TYPES`: `myid: MyStage`.
4. **Превью** — `src/ui/arenaArt.ts`, запись в `ARENA_ART` (SVG 160×90, только сплошные заливки — без `id` градиентов).
5. **Звук** (если новый тип декорации) — `AudioSystem.prop()`, ветка `case 'mykind'`.
6. **Проверка**:
   - `npm run arenas` — доступность, RANDOM, декорации за барьером и конечны, один и тот же бой в любом павильоне;
   - `npm run build`;
   - в браузере: павильон в меню и в бою, реакции декораций, переключение туда-обратно без роста `renderer.info.memory` (геометрии и текстуры должны возвращаться к тем же числам), Boss Fight и сезон поверх нового павильона, телефонные размеры.

Сезонный павильон для нового сезона: `availability: { kind: 'seasonal', themeId: '<тема сезона>', event: '<название события>' }` — он откроется сам, когда календарь включит этот сезон (см. `docs/SEASONAL_EVENTS.md`). Отдельной кнопки включения для игроков нет.
